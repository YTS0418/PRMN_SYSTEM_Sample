# docs/images — README に使う画像

各フォルダの README などで使う画像です。

- 画像の多くは、Lecture（[PRMN_SYSTEM_Lecture](https://github.com/YTS0418/PRMN_SYSTEM_Lecture)）の `images/` から**コピー**したものです。コピーの一覧は [`COPIES.txt`](COPIES.txt) にあり、元の画像とずれていないかは `bash tools/check-lecture-images.sh` で確認できます。
- このリポジトリで描いた図は、`.puml`（PlantUML）と `.svg` を両方置いています（`docker/` と `upstream/` の下）。作り方は、Lecture の [資料作成ルール](https://github.com/YTS0418/PRMN_SYSTEM_Lecture/blob/main/共通/資料作成ルール.md) にあります。
